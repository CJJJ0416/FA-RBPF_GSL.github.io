# 面向公共空间防爆防化任务的移动机器人自主巡检与危险源定位

英文题目：Autonomous Robotic Inspection and Hazard Source Localization for Explosive and Chemical Threat Prevention in Public Spaces

项目：Red bird project  
版本：研究提案大纲 2026年10月18日

本项目面向高铁站、地铁站和机场等公共空间，拟结合室内自主跨楼层导航、目标适配的气体感知与主动溯源，发现疑似危险信号、缩小来源范围，并向专业人员提供可复核的任务记录。首期选定一处室内区域、一类明确目标和一个机器人原型，先验证信号可测性，再评价主动巡检的定位效率与交接价值。

## 1 项目背景与任务定位

### 1.1 公共空间的防爆防化需求

围绕公共空间中疑似爆炸物及危险化学品相关异常线索的发现、复测、定位和移交开展研究。通过与运营、安全管理及专业检测人员沟通，确定一个真实、可重复描述的检查任务，记录触发方式、现行流程、查找成本、允许进入区域和来源确认方法。

气味和挥发性信号是候选感知线索，其与特定威胁的对应关系需要目标样本和参考测量支持。“防爆”作为任务目标涉及爆炸风险预防；机器人及载荷的防爆适用性属于另外需要满足的部署条件。两者分别评价。

### 1.2 室内与跨楼层场景

优先考虑具有房间分隔、楼梯、台阶和多层连通结构的站内运维空间。利用现有室内导航基础支撑移动采样，研究通行代价、可采样位置和信息收益之间的关系。跨楼层通行能力和跨楼层气味传播模型分别验证。

### 1.3 首期范围

- 应用任务：公共空间防爆防化巡检与危险源定位。
- 试点场所：由合作方提供的一处允许开展研究的室内区域。
- 目标对象：一种可获得代表性样本、可建立参考真值的目标信号或目标类别。
- 平台配置：单机器人，复用已有导航及测量接口。
- 实验方式：从非危险替代物和可控条件开始；目标物验证由具备相应条件的专业合作方承担。
- 输出层级：异常观测、疑似来源范围、候选检查对象和复核依据；具体物质识别、浓度与释放量估计按各自证据单独评价。

## 2 问题定义与利益相关方

### 2.1 核心问题

公共空间中的异常气体观测与可供安全人员执行的来源判断之间，存在测量、空间推理和信息交接的连续需求。本项目拟回答：机器人如何在有限采样和复杂室内通行条件下，找到最有信息价值的检查位置，缩小疑似危险源范围，并形成专业人员能够复核的结果。

### 2.2 主要利益相关方

| 角色 | 需要解决的问题 | 需要提供或接收的信息 |
| --- | --- | --- |
| 场所运营与安全管理人员 | 哪类任务值得试点，怎样融入现行流程 | 实际事件、区域权限、流程和验收要求 |
| 专业检测及应急人员 | 下一步优先检查哪里，依据是否充分 | 位置范围、观测记录、不确定性和复核入口 |
| 日常巡检人员 | 怎样减少重复查找并保留经验判断 | 现行路线、常见干扰、查找过程和结果反馈 |
| 材料与传感研究人员 | 目标释放是否可测，哪些因素造成混淆 | 代表性样本、参考分析、传感器响应和干扰条件 |
| 公众及现场工作人员 | 巡检怎样融入正常空间使用 | 与通行、隐私和现场管理相适应的任务安排 |

### 2.3 需要建立的需求证据

选择具体事件，梳理“谁发现、怎样确认、查找多久、谁接手、如何确认来源”。用实际流程记录及合作方复核完善需求，保留访谈、转述、现场观察和仪器测量的区别。此前课程材料中的占位访谈不作为本提案已经完成的实证调查。

## 3 研究目标与研究问题

### 3.1 目标信号的可靠检出

研究问题Q1：在限定目标和现场背景下，目标释放是否产生可重复的观测差异，怎样控制温湿度、背景变化、交叉响应及传感器动态造成的误判？

预期产出：目标与干扰样本库、采样规范、参考测量方案、传感器选型与异常检测基线。先建立可测性，再增加类别识别和定量估计。

### 3.2 与室内通行约束结合的主动采样

研究问题Q2：在房间分隔、楼梯和多层连通条件下，如何同时考虑信息收益、通行时间、采样停留和可达性，选择下一检查位置？

预期产出：与现有导航接口对接的主动采样模块、任务中止与观测不足的记录机制、固定路线对照实验。

### 3.3 目标适配的源位置估计

研究问题Q3：如何结合气体观测、机器人位姿、环境几何及可用的气流信息，逐步缩小来源范围，并识别模型不适用或证据不足的情况？

预期产出：源位置概率或候选区域、重复观测与定位一致性评价、误差及失败类型分析。既有RBPF-GSL等方法作为可复用基线，实际输运模型随试点通风条件验证和调整。

### 3.4 支持专业复核的任务交接

研究问题Q4：怎样把移动采样和概率估计转成接手人员可理解、可核查的任务结果，是否能减少无效检查或缩短形成有效检查线索的时间？

预期产出：包含时间、位置、原始观测、设备身份、来源范围、不确定性和未覆盖区域的任务记录，以及接手人员的复核反馈。

## 4 现有研究基础

### 4.1 机器人与导航

已有研究材料记录了Go2 EDU、Livox Mid360和Jetson计算平台，以及室内建图、导航和跨楼层规划工作。GlocalNav稿件提供分层全局与局部规划基础。上述能力支撑机器人通行与采样位置执行，公共空间中的适用性在选定路线中另行验证。

### 4.2 气体测量与源定位

已有ESP32与BME680采集原型，以及RBPF-GSL等室内源定位研究。中期报告表4.2记录10次乙醇源试验，成功判据为终止位置距源头小于1.5米，9次成功，1次误差5.77米。这些结果作为特定条件下的技术基础，目标物的检出、识别和定位性能分别建立新证据。

BME680的原始气体读数为电阻值。其相对响应和空气质量输出需要与目标物测量任务区分；特定物质的浓度、身份或危险程度由相应标定及参考检测支持。

### 4.3 补充研究展示与证据范围

GlocalNav 稿件的实机实验覆盖走廊、窄门和楼梯，每类场景重复10次。网页展示实验场景、Go2 EDU平台及楼梯避障执行画面，并提供[跨楼层巡检项目](https://gitee.com/fdsf3e2342/3d_navi_ros2)与[演示视频](https://www.bilibili.com/video/BV1XtrTBrEcE/)入口。

From Exploration Memory to Source Belief 稿件的实机研究使用轮式平台，搭载激光雷达、Jetson计算和BME680传感器，记录两次完成源位置估计的运行与一次在进入定位前结束的对照运行。其小样本支持流程可行性，不能与旧中期报告的10次试验合并为新的成功率。稿件同时包含单房间、多房间与办公室仿真环境。四足跨楼层导航与该气体源定位系统的整合，是后续研究任务。

公开展示限定于任务、平台、实验环境与高层能力，不包含核心算法、推导公式、内部流程图、伪代码及参数配置。

### 4.4 可选扩展

视觉对象识别可为候选检查对象分配设施身份；气流测量与预测可为采样提供信息。是否纳入首期，取决于它们能否改善选定任务。源定位、类别识别、浓度场重建和未来预测分别设置评价指标。

## 5 拟开展的技术路线

1. 明确目标任务：与交通或公共安全合作方确定一个具体事件类型、目标对象、试点区域及来源确认方式。
2. 验证样本可测性：比较目标、正常背景、常见干扰和混合条件，建立独立参考测量与传感器响应记录。
3. 建立异常检测基线：处理温湿度、传感器状态、响应恢复滞后及跨日期背景变化，保留未知类别。
4. 集成导航与主动采样：在可达区域内选择采样位置，记录行走、停留、测量和重定位开销。
5. 更新来源估计：融合历史与当前观测，输出疑似来源范围及置信信息，用重复采样检查一致性。
6. 形成交接结果：把估计结果关联至地图及可检查对象，提供专业人员复核所需的任务记录。

## 6 预期贡献与差异化验证

### 6.1 候选研究贡献

- 将室内及跨楼层通行约束与信息驱动采样结合，研究完整任务的采样效率。
- 建立限定目标下能够处理背景干扰与传感器动态的测量和估计流程。
- 将来源不确定性、未覆盖区域与复核依据纳入巡检结果，并评价交接可用性。

以上是需要通过相关工作比较和实验验证的研究方向。交通场景本身不直接构成方法创新，也不据此推断竞争较少。

### 6.2 对照方案

| 对照 | 主要回答的问题 |
| --- | --- |
| 当前人工检查流程 | 项目是否减少重复排查，交接结果是否有实际价值 |
| 固定位置监测或固定路线移动采样 | 主动选择位置是否带来任务收益 |
| 仅气体观测与加入几何或气流信息 | 新增信息是否改善定位及失败识别 |
| 有无传感器动态处理 | 时间对齐及响应补偿是否改善移动测量 |

## 7 验证阶段与评价指标

### 7.1 阶段一 需求与样本可测性

完成具体任务说明、目标与干扰样本、参考测量和传感器选型。阶段判断依据是目标在可接触采样条件下具有可重复信号，并能定义可核查的来源真值。

### 7.2 阶段二 受控机器人原型

在已知真值的室内环境集成异常复测、主动采样、源位置估计及任务记录。改变来源位置、机器人起点、背景与通风条件，设置无目标任务，并记录全部失败。

### 7.3 阶段三 小范围场景验证

在合作方认可的区域开展跨日期重复试验，与现行流程及固定路线对照，收集接手人员对结果的复核。具体样本量和验收阈值由前期数据及合作方需求确定。

### 7.4 评价指标

- 检出：以独立含目标任务为分母的检出率，无目标任务误报比例及单位巡检时间误报次数。
- 识别：限定类别的独立任务表现，以及对未知或证据不足情况的处理。
- 定位：全部任务的来源误差、来源范围、成功与失败数量及失败原因。
- 效率：任务触发至形成可交接结果的总时间，并拆分通行、采样和复核开销。
- 交接：能否指向可检查对象、是否减少重复查找、专业人员的复核结果。
- 运维：标定、清洁、漂移检查和传感器更换等工作量。

## 8 跨学科团队与合作资源

| 工作方向 | 适合的经验 | 主要交付 |
| --- | --- | --- |
| 机器人与人工智能 | 室内导航、规划、概率估计、系统集成 | 主动巡检原型、源估计与任务日志 |
| 材料与气体传感 | MOX或电子鼻、材料释放、采样、标定或参考分析 | 可测性结论、测量方案与样本数据 |
| 数据科学 | 时序数据、异常检测、实验设计、独立验证 | 数据规范、检测模型与评价报告 |
| 交通与公共安全 | 场所运营、安全流程、现场对接、专业检测 | 具体任务、试点条件与结果复核流程 |

按任务需要补充硬件集成和成本评估支持。工作方向是功能配置，可由成员兼任；具体分工随人员背景与试点任务确定。

## 9 预期成果

1. 一个经合作方确认的公共空间防爆防化巡检任务定义。
2. 一套限定目标与干扰条件的样本数据及采样规范。
3. 一个集成导航、主动采样、来源估计和任务记录的单机器人原型。
4. 一份包含全部任务结果、对照实验与失败分析的验证报告。
5. 一套可由专业人员复核的来源线索与任务交接模板。
6. 一个介绍研究目标、现有基础、验证计划和团队需求的中英文宣传网页。
